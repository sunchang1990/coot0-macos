### set_draw_axes

Python: `set_draw_axes(i)`  
Scheme: `(set-draw-axes i)`

Draw the axes in the top left?

0 off, 1 on

Arguments: i (a whole number). Returns: nothing.

| | Example | When tried (test data, no window) |
|---|---|---|
| Python | `set_draw_axes(1)` | ran (no return value) |
| Scheme | `(set-draw-axes 1)` | ran (no return value) |
