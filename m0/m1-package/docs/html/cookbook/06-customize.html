6. Customize Coot: toolbar, menus, keys, colours, preferences

*Each recipe stands alone and loads its own copy of the test files (run recipe 1.1 once first; with your own data use your molecule numbers instead: How to use a recipe).*

Put the lines you want every time into a startup file (recipe 6.8). In coot0 the windows, menus and toolbar are made by Python, so buttons and menus are added with Python functions; from Scheme you call them with run-python-script (the Scheme GUI library of the original Coot is not part of coot0). run-python-command evaluates one Python expression and returns its value; for several lines, write them to a .py file and run it with run-python-script, as below.

6.1 A toolbar button that runs your code

The function runs when the button is pressed. Here: refine the residue at the centre of the screen and its neighbours.

def refine_here():
    ar = active_residue()                       # [imol, chain, resno, ins, atom, alt] of the residue in the centre
    if ar:
        imol, spec = ar[0], [ar[1], ar[2], ar[3]]
        refine_residues(imol, [spec] + residues_near_residue(imol, spec, 4.0))

coot_toolbar_button("Refine here", refine_here, tooltip="Sphere refine around the centre")
(call-with-output-file "my-button.py"
  (lambda (port) (display "
def refine_here():
    ar = active_residue()
    if ar:
        imol, spec = ar[0], [ar[1], ar[2], ar[3]]
        refine_residues(imol, [spec] + residues_near_residue(imol, spec, 4.0))
coot_toolbar_button('Refine here', refine_here, tooltip='Sphere refine around the centre')
" port)))
(run-python-script "my-button.py")

6.3 A key that runs your code

Press v in the graphics window to refine 3 residues on each side of the centre.

def refine_triple():
    ar = active_residue()
    if ar:
        refine_zone(ar[0], ar[1], ar[2] - 3, ar[2] + 3, ar[5])

add_key_binding("Refine 7 residues", "v", refine_triple)
(add-key-binding "Refine 7 residues" "v"
  (lambda ()
    (let ((ar (active-residue)))
      (if ar (refine-zone (list-ref ar 0) (list-ref ar 1) (- (list-ref ar 2) 3) (+ (list-ref ar 2) 3) (list-ref ar 5))))))

Keys Coot already uses cannot be taken: the binding is made but never runs, or Coot does its own thing as well. Coot's own keys: F5 (Model/Fit/Refine), F6 (Go To Atom), F7 (Display Manager), F8 (screenshot), the digits, arrows, . , - + =, Space, Return, Escape, c (crosshairs), d f (clipping), i (spin), l (label), m n (zoom), o O (next / previous NCS chain), p (update Go To Atom), s (re-contour), u (undo move), and Ctrl with C, D, G, I, L, R, S, X, Y, Z. Keys from Calculate > ... > Install Template Keybindings (if you installed them) are taken as well; they use most other letters except v. Help > Keyboard Shortcuts (build 28) lists all keys and your own bindings.

  • Ctrl keys (Python): add_key_binding("Refine 7 residues", "Control_t", refine_triple) for Ctrl-T (build 28 or later). A key and its Ctrl- version are separate bindings.
  • Function keys on a Mac: F1-F12 control the Mac (brightness, sound, ...); press fn with them to send F9 etc. to Coot, or switch it in System Settings > Keyboard > Keyboard Shortcuts > Function Keys.

6.4 Colours: map, background, symmetry

Red, green, blue from 0 to 1. Like every recipe, this one loads what it needs (here the test map, so it has a map to colour). For a map you already have, use its number from the Display Manager instead, e.g. imol_map = 1. The map colour can only be set while Coot has its window (it is not run in the automatic test).

imol_map = make_and_draw_map("rnasa-1.8-all_refmac1.mtz", "FWT", "PHWT", "", 0, 0)   # or: imol_map = 1
set_map_colour(imol_map, 0.3, 0.6, 1.0)     # light blue map
set_background_colour(1.0, 1.0, 1.0)        # white background
set_symmetry_colour(0.8, 0.8, 0.2)          # yellow symmetry copies
(define imol-map (make-and-draw-map "rnasa-1.8-all_refmac1.mtz" "FWT" "PHWT" "" 0 0))   ; or: (define imol-map 1)
(set-map-colour imol-map 0.3 0.6 1.0)
(set-background-colour 1.0 1.0 1.0)
(set-symmetry-colour 0.8 0.8 0.2)

6.7 Preferences you can set from a script

A few that people often change (all are remembered only for the session unless they are in a startup file): (Not set_refinement_immediate_replacement(1): as a lasting setting it takes away the Accept window of every refinement you make with the mouse; it belongs in scripts, switched off again at the end, chapter 4.)

set_map_radius(12)                          # draw maps 12 A around the centre
set_auto_recontour_map(1)                   # re-contour maps when the centre moves
set_smooth_scroll_flag(0)                   # jump instead of slide when going to an atom
set_default_bond_thickness(4)               # bond width of models read from now on
set_add_terminal_residue_do_post_refine(1)  # refine new terminal residues
(set-map-radius 12)
(set-auto-recontour-map 1)
(set-smooth-scroll-flag 0)
(set-default-bond-thickness 4)
(set-add-terminal-residue-do-post-refine 1)

6.8 Run your settings every time Coot starts

coot0 keeps its own home folder: ~/Library/Application Support/coot0/home/ (installed with install.sh; in a folder you unpacked yourself it is home/ inside that folder). Python and Scheme files in home/.coot-preferences/ are run at every start, in alphabetical order. This recipe writes such a file.

import os
prefs = os.path.join(os.environ["HOME"], ".coot-preferences")
os.makedirs(prefs, exist_ok=True)
with open(os.path.join(prefs, "my-settings.py"), "w") as f:
    f.write("set_default_bond_thickness(4)\n")
    f.write("set_map_radius(12)\n")
print("written to", prefs)
(let ((prefs (string-append (getenv "HOME") "/.coot-preferences")))
  (if (not (file-exists? prefs)) (mkdir prefs))
  (call-with-output-file (string-append prefs "/my-settings.scm")
    (lambda (port)
      (display "(set-default-bond-thickness 4)\n" port)
      (display "(set-map-radius 12)\n" port)))
  (format #t "written to ~a~%" prefs))

Inside Coot, HOME is coot0's own home folder (not your Mac home folder), so the file lands in the right place. Delete the file to go back to the defaults.
