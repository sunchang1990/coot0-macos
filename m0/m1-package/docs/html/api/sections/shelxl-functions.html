chain_id_for_shelxl_residue_number

Python: chain_id_for_shelxl_residue_number(imol, resno)
Scheme: (chain-id-for-shelxl-residue-number imol resno)

Returns the chain id for the given residue. Return Py_False if can't do it/fail.

Arguments: imol (a whole number), resno (a whole number). Returns: a value (see the result of the example). Also available in Python as chain_id_for_shelxl_residue_number_py.

ExampleWhen tried (test data, no window)
Pythonfirst write_shelx_ins_file(0, "tut.ins"), then imol_s = read_shelx_ins_file("tut.ins", 0), then chain_id_for_shelxl_residue_number(imol_s, 1041)ran, returned 'B'
Schemefirst (write-shelx-ins-file 0 "tut.ins"), then (define imol-s (read-shelx-ins-file "tut.ins" 0)), then (chain-id-for-shelxl-residue-number imol-s 1041)ran, returned "B"

Example written and checked by hand on the test data. Expected: the chain that holds SHELXL residue number 1041 (chain B's residues get +1000 in the .ins file); False if none.

Python and Scheme gave the same answer.
