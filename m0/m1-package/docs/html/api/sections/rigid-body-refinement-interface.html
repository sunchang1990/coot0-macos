rigid_body_refine_by_residue_ranges

Python: rigid_body_refine_by_residue_ranges(imol, residue_ranges)
Scheme: (rigid-body-refine-by-residue-ranges imol residue-ranges)

rigid body refine using residue ranges. residue_ranges is a list of residue ranges. A residue range is [chain_id, resno_start, resno_end].

Arguments: imol (a whole number), residue_ranges (a list or value). Returns: a value (see the result of the example). Also available in Python as rigid_body_refine_by_residue_ranges_py. Also available in Scheme as rigid-body-refine-by-residue-ranges-scm.

ExampleWhen tried (test data, no window)
Pythonrigid_body_refine_by_residue_ranges(0, [["A", 41, 45]])ran, returned True
Scheme(rigid-body-refine-by-residue-ranges 0 (list (list "A" 41 45)))ran, returned #t

Example written and checked by hand on the test data. Expected: rigid-body refines the listed ranges [chain, start, end] against the refinement map; True when the fit was done.

Python and Scheme gave the same answer.
