highly_coordinated_waters

Python: highly_coordinated_waters(imol, coordination_number, dist_max)
Scheme: (highly-coordinated-waters imol coordination-number dist-max)

return a list first of waters, second metals that are coordinated with at least coordination_number of other atoms at distances less than or equal to dist_max. Return Python false on not able to make a list, otherwise a list of atoms and neighours. can return Python False if imol is not a valid molecule.

Arguments: imol (a whole number), coordination_number (a whole number), dist_max (a number). Returns: a value (see the result of the example). Also available in Python as highly_coordinated_waters_py. Also available in Scheme as highly-coordinated-waters-scm.

ExampleWhen tried (test data, no window)
Pythonhighly_coordinated_waters(0, 1, 1.0)ran, returned [[], []]
Scheme(highly-coordinated-waters 0 1 1.0)ran, returned (())

Python and Scheme gave different answers (see the table: often only because the example changed the data, or a list is ordered differently).
