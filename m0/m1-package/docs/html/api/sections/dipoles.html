add_dipole

Python: add_dipole(imol, chain_id, res_no, ins_code)
Scheme: (add-dipole imol chain-id res-no ins-code)

generate a dipole from all atoms in the given residues.

Arguments: imol (a whole number), chain_id (text), res_no (a whole number), ins_code (text). Returns: a value (see the result of the example). Also available in Python as add_dipole_py. Also available in Scheme as add-dipole-scm.

ExampleWhen tried (test data, no window)
Pythonadd_dipole(0, "A", 41, "")ran, returned [-1, [0.0, 6.5193059465536e-311, 3.56e-322]]
Scheme(add-dipole 0 "A" 41 "")ran, returned (-1 (0.0 6.5193059465536e-311 3.56e-322))

Python and Scheme gave the same answer.

add_dipole_for_residues

Python: add_dipole_for_residues(imol, residue_specs)
Scheme: (add-dipole-for-residues imol residue-specs)

add a dipole given a set of residues. Return a dipole description.

Arguments: imol (a whole number), residue_specs (a list or value). Returns: a value (see the result of the example). Also available in Python as add_dipole_for_residues_py. Also available in Scheme as add-dipole-for-residues-scm.

ExampleWhen tried (test data, no window)
Pythonadd_dipole_for_residues(0, [["A", 41, ""], ["A", 42, ""]])ran, returned [-1, [1e-323, 2.1537237812e-313, 2.15390748945e-313]]
Scheme(add-dipole-for-residues 0 (list (list "A" 41 "") (list "A" 42 "")))ran, returned (-1 (1.0e-323 2.1537237338e-313 2.1539075685e-313))

Python and Scheme gave the same answer.
