do_clipped_surface

Python: do_clipped_surface(imol, residue_specs)
Scheme: (do-clipped-surface imol residue-specs)

draw the surface of the imolth molecule clipped to the residues given by residue_specs

Arguments: imol (a whole number), residue_specs (a list or value). Returns: nothing. Also available in Python as do_clipped_surface_py. Also available in Scheme as do-clipped-surface-scm.

ExampleWhen tried (test data, no window)
Pythondo_clipped_surface(0, [["A", 41, ""], ["A", 42, ""]])ran (no return value)
Scheme(do-clipped-surface 0 (list (list "A" 41 "") (list "A" 42 "")))ran (no return value)

do_surface

Python: do_surface(imol, istate)
Scheme: (do-surface imol istate)

draw surface of molecule number imol

if state = 1 draw the surface (normal representation goes away)

if state = 0 don't draw surface

Arguments: imol (a whole number), istate (a whole number). Returns: nothing.

ExampleWhen tried (test data, no window)
Pythondo_surface(0, 1)ran (no return value)
Scheme(do-surface 0 1)ran (no return value)
