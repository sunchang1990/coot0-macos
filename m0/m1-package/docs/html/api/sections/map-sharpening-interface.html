sharpen

Python: sharpen(imol, b_factor)
Scheme: (sharpen imol b-factor)

Sharpen map imol by b_factor (note (of course) that positive numbers blur the map).

Arguments: imol (a whole number), b_factor (a number). Returns: nothing.

ExampleWhen tried (test data, no window)
