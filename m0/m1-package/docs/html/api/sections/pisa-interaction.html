handle_pisa_interfaces

Python: handle_pisa_interfaces(interfaces_description_py)
Scheme: (handle-pisa-interfaces interfaces-description-scm)

the scripting interface, called from parsing the PISA XML interface description

An interface_description_scm is a record detailing the interface. A record contains the bsa, asa, and 2 molecule records. Molecule records contain list of residue records. The interface (dots) is be made from these lists of residue records. Note of course that imol_2 (or 1) can be a symmetry copy of (part of) mol_1 (or 2).

Return the dot indexes (currently -1)

Arguments: interfaces_description_py (a list or value). Returns: a value (see the result of the example). Also available in Python as handle_pisa_interfaces_py. Also available in Scheme as handle-pisa-interfaces-scm.

ExampleWhen tried (test data, no window)
Pythonhandle_pisa_interfaces([])ran, returned -1
Scheme(handle-pisa-interfaces (list))ran, returned -1

Example written and checked by hand on the test data. Expected: internal: called by the PISA XML parser with the interface records; an empty list returns -1.

Note: a real description is a nested record list made by parse_pisa_xml.py (molecule pairs, bonds, areas) and ends in a tree-view window; only the empty case was run

Python and Scheme gave the same answer.
