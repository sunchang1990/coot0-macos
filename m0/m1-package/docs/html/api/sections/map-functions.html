average_map

Python: average_map(map_number_and_scales)
Scheme: (average-map map-number-and-scales)

make an average map from the map_number_and_scales (which is a list of pairs [map_number, scale_factor] (the scale factors are typically 1.0 of course). The output map is in the same grid as the first (valid) map. Return -1 on failure to make an averaged map, otherwise return the new map molecule number.

Arguments: map_number_and_scales (a list or value). Returns: a whole number. Also available in Python as average_map_py. Also available in Scheme as average-map-scm.

ExampleWhen tried (test data, no window)
Pythonfirst imap2 = map_from_mtz_by_calc_phases("rnasa-1.8-all_refmac1.mtz", "FGMP18", "SIGFGMP18", 0), then average_map([[1, 1.0], [imap2, 1.0]])ran, returned 4; changed: new molecule 4 (map, averaged-map); graphics_n_molecules(): 4 -> 5
Schemefirst (define imap2 (map-from-mtz-by-calc-phases "rnasa-1.8-all_refmac1.mtz" "FGMP18" "SIGFGMP18" 0)), then (average-map (list (list 1 1.0) (list imap2 1.0)))ran, returned 4; changed: new molecule 4 (map, averaged-map); graphics_n_molecules(): 4 -> 5

Example written and checked by hand on the test data. Expected: returns a new map that is the scaled average of the listed [map, scale] pairs (on the first map's grid).

Python and Scheme gave the same answer.
