Examples use the test data: molecule 0 = tutorial-modern.pdb, molecule 1 = the map made from rnasa-1.8-all_refmac1.mtz (FWT/PHWT). See How to read this reference.

SMILES_for_comp_id

Python: SMILES_for_comp_id(comp_id)
Scheme: (SMILES-for-comp-id comp-id)

this can throw an exception

Arguments: comp_id (text). Returns: a value (see the result of the example).

ExampleWhen tried (test data, no window)
PythonSMILES_for_comp_id("ALA")ran, returned 'C[C@H](N)C(O)=O'
Scheme(SMILES-for-comp-id "ALA")ran, returned "C[C@H](N)C(O)=O"

Python and Scheme gave the same answer.
