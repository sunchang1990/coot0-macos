get_pointer_position_frac

Python: get_pointer_position_frac()

return the [x,y] position of the pointer in fractional coordinates.

the origin is top-left. may return false if pointer is not available

Arguments: none. Returns: a value (see the result of the example). Also available in Python as get_pointer_position_frac_py. Python only (see one-language-only).
