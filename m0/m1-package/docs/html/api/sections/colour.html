set_user_defined_colours_py

Python: set_user_defined_colours_py(colour_list_py)

by default user-defined colour indices will use a colour wheel but here we can set them ourselves by passing something like: [1, [0.2, 0.3, 0.4]], [2, [0.6, 0.4, 0.2]]] i.e. a colour for each colour index. If the colour index goes beyond the limit, or there is a missing value, then colour will be [0.5, 0.5, 0.5]

Arguments: colour_list_py (a list or value). Returns: nothing. Python only (see one-language-only).
