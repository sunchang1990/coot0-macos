display_python

Python: display_python(o)

This is a common denominator really. It does not depend on mmdb, but it can't be declared in c-interface.h because then we'd have to include c-interface.h which would cause (resolvable, I think, not checked) problems. return a python string, decode to c++ using scm_to_locale_string();

Arguments: o (a list or value). Returns: a value (see the result of the example). Python only (see one-language-only).

ExampleWhen tried (test data, no window)
Pythondisplay_python([1, "a", 2.5])ran, returned "object: [1, 'a', 2.5]\n"

Example written and checked by hand on the test data. Expected: a printable string describing the Python object (internal helper for messages). (Python only.).

safe_python_command_with_unsafe_thread

Python: safe_python_command_with_unsafe_thread(cmd)

Arguments: cmd (text). Returns: nothing. Python only (see one-language-only).

ExampleWhen tried (test data, no window)
Pythonsafe_python_command_with_unsafe_thread("print('hello')")not run: crashes Coot when called from Python: it releases the Python lock and then runs Python code without it (internal helper)

Example written and checked by hand on the test data. Expected: runs a Python command string with the interpreter lock released; meant only for C++ code, not for scripts.

Note: Calling it from a script always crashes (Py_BEGIN_ALLOW_THREADS then PyRun_SimpleString). Use run_python_command / exec instead.
