alignment_mismatches

Python: alignment_mismatches(imol)
Scheme: (alignment-mismatches imol)

do a internal alignment of all the assigned sequences, return a list of mismatches that need to be made to model number imol to match the input sequence.

Return a list of mutations deletions insetions. Return False on failure to align (e.g. not assigned sequence) and the empty list on no alignment mismatches.

Arguments: imol (a whole number). Returns: a value (see the result of the example). Also available in Python as alignment_mismatches_py. Also available in Scheme as alignment-mismatches-scm.

ExampleWhen tried (test data, no window)
Pythonalignment_mismatches(0)ran, returned False
Scheme(alignment-mismatches 0)ran, returned #f

Python and Scheme gave the same answer.
