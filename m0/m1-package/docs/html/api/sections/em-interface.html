scale_cell

Python: scale_cell(imol_map, fac_u, fac_v, fac_w)
Scheme: (scale-cell imol-map fac-u fac-v fac-w)

Scale the cell, for use with EM maps, where the cell needs to be adjusted. Use like: (scale-cell 2 1.012 1.012 1.012). Return error status, 1 means it worked, 0 means it did not work.

Arguments: imol_map (a whole number), fac_u (a number), fac_v (a number), fac_w (a number). Returns: a whole number.

ExampleWhen tried (test data, no window)
Pythonscale_cell(1, 1.01, 1.01, 1.01)ran, returned 0
Scheme(scale-cell 1 0.99 0.99 0.99)ran, returned 0

Example written and checked by hand on the test data. Expected: the cell of map 1 is scaled by 1% on each axis (see cell(1)); return value is always 0.

Note: Return value is always 0 (molecule_class_info_t::scale_cell never sets it), even on success.

Python and Scheme gave the same answer.
