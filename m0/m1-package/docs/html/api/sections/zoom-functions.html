scale_zoom

Python: scale_zoom(f)
Scheme: (scale-zoom f)

scale the view by f

external (scripting) interface (with redraw) @param f the smaller f, the bigger the zoom, typical value 1.3. Values outside the range 0.5 to 1.8 are filtered out

Arguments: f (a number). Returns: nothing.
