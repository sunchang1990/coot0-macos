mark_atom_as_fixed

Python: mark_atom_as_fixed(imol, atom_spec, state)
Scheme: (mark-atom-as-fixed imol atom-spec state)

Arguments: imol (a whole number), atom_spec (a list or value), state (a whole number). Returns: a value (see the result of the example). Also available in Python as mark_atom_as_fixed_py. Also available in Scheme as mark-atom-as-fixed-scm.

ExampleWhen tried (test data, no window)
Pythonmark_atom_as_fixed(0, ["A", 41, "", " CA ", ""], 1)ran, returned True
Scheme(mark-atom-as-fixed 0 (list "A" 41 "" " CA " "") 1)ran, returned #f

Python and Scheme gave different answers (see the table: often only because the example changed the data, or a list is ordered differently).
