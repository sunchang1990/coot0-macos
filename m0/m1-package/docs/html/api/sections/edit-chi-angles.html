edit_chi_angles

Python: edit_chi_angles(imol, chain_id, resno, ins_code, altconf)
Scheme: (edit-chi-angles imol chain-id resno ins-code altconf)

display the edit chi angles gui for the given residue

return a status of 0 if it failed to fined the residue, return a value of 1 if it worked.

Arguments: imol (a whole number), chain_id (text), resno (a whole number), ins_code (text), altconf (text). Returns: a whole number.

set_find_hydrogen_torsion

Python: set_find_hydrogen_torsion(state)
Scheme: (set-find-hydrogen-torsions state)

show torsions that rotate hydrogens in the torsion angle manipulation dialog. Note that this may be needed if, in the dictionary cif file torsion which have as a 4th atom both a hydrogen and a heavier atom bonding to the 3rd atom, but list the 4th atom as a hydrogen (not a heavier atom).

Arguments: state (a whole number). Returns: nothing. Also available in Python as set_find_hydrogen_torsions.
