Scripting reference > Save Coordinates (4 functions)

Examples use the test data: molecule 0 = tutorial-modern.pdb, molecule 1 = the map made from rnasa-1.8-all_refmac1.mtz (FWT/PHWT). See How to read this reference.

save_coordinates

Python: save_coordinates(imol, filename)
Scheme: (save-coordinates imol filename)

save coordinates of molecule number imol in filename

Returns status 1 is good (success), 0 is fail.

Arguments: imol (a whole number), filename (text). Returns: a whole number.

ExampleWhen tried (test data, no window)
Pythonsave_coordinates(0, "tutorial-modern.pdb")ran, returned 0
Scheme(save-coordinates 0 "tutorial-modern.pdb")ran, returned 0

Python and Scheme gave the same answer.
